\begin{abstract}
\noindent
A scientific repair can be one line long and still be hard to find, because the code that must change
is identified by what it computes rather than by where it sits. We ask whether a repair agent benefits
from a prepared, queryable account of that structure. Our representation, \emph{computation and
boundary evidence} (CBE), records which expressions produce a returned quantity, which conditions
guard them, which public definitions document them, and which calls leave the repository to a named
provider. It is built from parsers alone, delivered through three query endpoints beside the agent's
ordinary shell tools, and costs no additional time or tokens. We evaluate it on all 119 tasks of
SWE-bench Science with DeepSeek V4.1 Flash, under a matched allowance and three to four replicates per
task. CBE solves the same number of held-out attempts as the baseline while generating 13.7\% fewer
output tokens, and its effect separates by discipline: it gains 22.2 percentage points in mechanics
and 9.7 in materials science, but loses 16.7 in biomedical engineering and 9.5 in biology, where the
defect is an ordinary software fault dressed in scientific language. Replicates show that about a fifth
of tasks change outcome between identical runs, so only differences of this size are measurable at all.
\end{abstract}

\section{Introduction}
A rotation applied in the wrong reference frame, a unit system assumed rather than converted, a boundary
treated as closed when the data are open: failures in scientific software are often one line wide, and
finding that line requires knowing which expression produces the quantity that a public interface
promises. An agent working with shell tools alone has to reconstruct that structure from text search.
This is possible, but it spends the same budget that the repair itself needs.

We ask whether that reconstruction can be supplied in advance, cheaply, and queried on demand. Our
representation, \emph{computation and boundary evidence} (CBE), is prepared once per task by parsers
and analyzers: it records computations together with the source spans that anchor their results,
conditions and findings that guard them, documented public definitions, and every call that crosses a
repository boundary, classified as internal, external with a named provider, or unresolved. The agent
reaches it through three endpoints --- search, inspection and an optional record --- while keeping its
usual tools. Preparation makes no model call, and the endpoints add no allowance.

We evaluate this against an unchanged repair baseline on the complete SWE-bench Science benchmark
\cite{xu2026swebenchscience}. Our contributions are:

\begin{enumerate}
  \item \textbf{A preparation pipeline that needs no model.} File ranking follows execution evidence and
        boundary callers; Python is parsed with Tree-sitter and C, C++, Fortran and Cython with Joern
        code property graphs, with explicit fallback when a frontend is unavailable.
  \item \textbf{Boundary classification as first-class evidence.} Every call is labelled internal,
        external with a provider, or unresolved. External providers are treated as interfaces assumed
        correct, which keeps the search inside the repository instead of guessing at library internals.
  \item \textbf{A matched evaluation with replicate structure.} We report solve rate, generated tokens,
        partial credit and per-discipline outcomes over 757 verified attempts, and we quantify how much
        of the benchmark moves between identical runs.
\end{enumerate}

\section{Related work}
Linking bug reports to code through intermediate structure beats text similarity, and narrowing the role
of retrieved context avoids pollution from loosely related artifacts
\cite{niu2023ablots,niu2023rat,niu2025tvr,pan2025coverage}. Representations of scientific code exist as
well: code property graphs model control and data flow \cite{yamaguchi2014cpg}, incremental parsers make
multi-language parsing routine \cite{treesitter}, and model-extraction efforts recover equations and
semantics from scientific source \cite{skema2024gromet,automates2020}. That work is offline or code-only.
CBE differs in delivery: the same structure, distilled to computations and boundaries and handed to a
repair agent inside an unchanged harness.

\section{What the agent receives}
Preparation is a single pass with no model call: files are ranked so that execution evidence and boundary
callers precede shallow entry points, and parsers then produce the store. Across the 94 tasks whose
prepared bundles are frozen, a task yields a median of 296 scientific objects, and the boundaries recorded
during the held-out runs comprise 12{,}794 external calls, 1{,}890 unresolved ones and 534 internal ones,
with \texttt{numpy} alone accounting for 1{,}554 external cases. The agent reaches the store through
\texttt{science\_find}, \texttt{science\_inspect} (relationships, definitions, source and contracts) and
\texttt{science\_note}, an optional record that never gates repair. Figure~\ref{fig:flow} shows the path
and a boundary record of the kind the agent receives.

\section{Protocol}
Thirty development tasks were used for iteration and 89 were locked before the reported runs, so the
held-out partition is the only basis for the headline claim. Discipline labels come from the benchmark's
own task inventory, re-extracted and validated against its published counts rather than annotated by us.
Both arms use the same model (DeepSeek V4.1 Flash at temperature $0$ with a pinned hash seed), image,
1800-second budget and verifier; the verifier runs only after the repair stops and neither container has
network. A solve means the official reward, and the private-test pass fraction is kept as partial credit.
The held-out partition was replicated three times and development four times, and every number below
regenerates from verifier receipts through one analysis script.

\paragraph{Parity costs fewer generated tokens.} CBE solves as many held-out attempts as the baseline
(Table~\ref{tab:main}, Figure~\ref{fig:parity}), and the paired comparison over tasks is flat: 74 tie,
seven favour CBE and eight favour the baseline, with a sign test that cannot separate them. Development repeats the
pattern. What changes is cost. CBE generates 13.7\% fewer output tokens, close to 40{,}000 per attempt
instead of 46{,}000, spends slightly more input because it still opens files, and takes about a minute
more wall-clock time per attempt. Partial credit moves the other way by a small margin, which matches a
narrower search: the agent either finds the right computation or stops before it.

\paragraph{Gains and losses separate by discipline.}
\begin{figure}[t]
  \centering
  \includegraphics[width=\linewidth]{../figures/out/fig_domains.pdf}
  \caption{Wins and losses separate by discipline. \textbf{A}~held-out tasks; \textbf{B}~development
  tasks. Each row is one domain, labelled with its task count: circles are the baseline arm, squares
  CBE, and the right column gives the difference in percentage points. Where the two markers
  coincide the domain did not move at all.}
  \label{fig:domains}
\end{figure}
Aggregate parity hides opposing effects (Figure~\ref{fig:domains}). Mechanics gains 22.2 percentage points,
from no solves to two of nine attempts, astronomy 12.4 and materials science 9.7, while biomedical
engineering loses 16.7 and biology 9.5; chemistry, physics and mathematics are unchanged to the last
attempt. Development shows the same shape from the other side, with mathematics gaining three solves where
the baseline had none. The benchmark's knowledge-ablation flag shows no interaction, and language strata
are uninformative because 81 of the 89 held-out tasks are pure Python.

The tasks themselves name the mechanism. CBE gains on tasks 020, 042, 067, 074, 084, 103 and 116, and
loses on 022, 029, 053, 056, 063, 087, 093 and 098. Task 103 asks for the stiffness matrices of a symmetric composite laminate; CBE
solved it twice in three replicates against no baseline solve, inspecting the ply-angle computation and the
library boundaries it calls. Task 022 asks for a volume-to-surface projection in a neuroimaging toolkit,
and the comparison inverts: the baseline solved it twice and CBE never did, because the trajectory reasoned
about projection mathematics before touching the atlas label mapping the instruction describes. When the
defect is a computation, structure locates it; when the defect is ordinary code under scientific prose,
structure distracts from it.

\paragraph{Replication bounds what is measurable.}
\begin{figure}[t]
  \centering
  \includegraphics[width=\linewidth]{../figures/out/fig_stability.pdf}
  \caption{Most tasks never move. \textbf{A}~held-out tasks by the number of replicate runs that
  solved them: 60 (baseline) and 61 (CBE) are never solved, 11 and 10 are always solved.
  \textbf{B}~share of tasks solved by at least one of $k$ pooled runs, $k \le 3$. Across arms,
  eighteen tasks flip inside one arm and fifteen differ between arms.}
  \label{fig:stability}
\end{figure}
Three replicates make the measurement problem visible (Figure~\ref{fig:stability}). Sixty tasks are never
solved by the baseline and 61 never by CBE, eleven and ten are solved every time, 18 change outcome
between identical runs within one arm, and the arms disagree on 15 tasks in total. A single run would
attribute a few percentage points to the method with no basis.

\paragraph{Reduced reasoning effort recovers what high effort lost.} On the development partition the
baseline leads at high effort and CBE leads at low effort, and on the 20-task subset evaluated at both
levels the high-effort deficit disappears once effort is reduced. The two tasks recovered under low
effort are the same two that were lost under high effort, which is what one expects if external evidence
substitutes for deliberation rather than adding capability. The agent used the endpoints throughout that
subset: 61 inspections, 10 searches and 20 optional records across 20 tasks.

\section{Discussion and conclusion}
One reading of these results is that scientific structure is not useful to a repair agent, since average
solve rate does not move. The other is that its usefulness is domain-dependent: it helps where the defect
is a computation and hurts where the defect is code that merely lives near one. The discipline split, the
discordant tasks and the partial-credit shift all point at the second reading.

Four limits bound the claim. One model at one budget produced every number; single-task disciplines are
descriptive, and only the aggregate held-out comparison supports inference; unparseable expressions are
recorded as unsupported and external calls are labelled rather than verified, so a classification error
would silently shrink the search space; and development tasks are optimistic by construction. The design
consequence is to offer scientific structure conditionally, with a signal that the defect is computational
before an agent commits to reading mathematics.

report. LLM coding assistants implemented harness plumbing, parsers and figures, and helped revise prose.
